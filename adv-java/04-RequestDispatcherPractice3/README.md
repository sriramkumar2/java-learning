# RequestDispatcher3

## Project Description

This is a simple Java Web Application developed to understand the `RequestDispatcher.include()` method. In this project, one Servlet includes the output of another Servlet. After including the second Servlet's output, the first Servlet continues its execution.

## Technologies Used
- Java
- Jakarta Servlets
- HTML
- Apache Tomcat 10.1
- Eclipse IDE

## Concepts Learned

| Concept | Explanation |
|---|---|
| RequestDispatcher | It is used to send a request from one Servlet to another Servlet or resource. |
| getRequestDispatcher() | It is used to identify the Servlet or resource that we want to include or forward to. |
| include() | It includes the output of another Servlet in the current response. |
| Request Object | It carries the data sent by the browser to the Servlet. |
| Response Object | It is used to send the output from the Servlet back to the browser. |
| Shared Request and Response | Both Servlets use the same request and response objects when we use the include() method. |
| Servlet Execution | After including the second Servlet, the first Servlet continues executing its remaining code. |
| setContentType() | It tells the browser what type of content the Servlet sends, such as HTML. |

## Project Structure

- `index.html` – It contains a Submit button. When the user clicks the button, it sends a GET request to FirstServlet.
- `FirstServlet.java` – It receives the request, displays its own content and includes the output of SecondServlet using the include() method.
- `SecondServlet.java` – It generates additional HTML content. This content is included in the response generated by FirstServlet.

## Application Flow

1. The user opens the index.html page in the browser.
2. The user clicks the Submit button.
3. The browser sends a GET request to FirstServlet.
4. FirstServlet receives the request and starts executing.
5. FirstServlet displays its own heading in the response.
6. FirstServlet creates a RequestDispatcher object using getRequestDispatcher().
7. FirstServlet calls `include(request, response)` to include SecondServlet.
8. SecondServlet executes and generates its HTML content.
9. The output generated by SecondServlet is added to the same response.
10. After SecondServlet finishes, FirstServlet continues executing its remaining code.
11. Finally, the browser displays the complete output from both Servlets.

## Learning Objective

The main objective of this project is to understand how the `RequestDispatcher.include()` method works. It helps us learn how one Servlet includes the output of another Servlet and continues its own execution after the include operation.
